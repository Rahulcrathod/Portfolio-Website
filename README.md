# Rahul C Rathod — Portfolio

# Live Site
https://portfolio-website-student.netlify.app/

This is a Vite + React + Tailwind portfolio, pre-filled with your details and two GitHub projects.

## Quick start

```bash
npm install
npm run dev
```

## Build & Deploy (Netlify)
```bash
npm run build
# then either drag the dist/ folder to Netlify
# or use the CLI:
# npm i -g netlify-cli
# netlify login
# netlify init  (link to rahulcrathod.netlify.app)
# netlify deploy --prod
```

## Where to edit

- **src/data.js** → name, socials, email, projects
- **src/assets/headshot.jpg** → your photo
- **src/App.jsx** → layout and sections
